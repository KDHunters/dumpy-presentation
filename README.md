## 발표 구성 및 조작

기존 표지 뒤에 문제 제기·인터뷰·서비스 소개를 배치하고, 기능 소개 자리 뒤에는 기존 기술 및 후반부 자료를 유지했습니다. 총 27장입니다. 기능 소개 영상은 아직 자리표시자입니다.

- 좌우 방향키 또는 PageUp/PageDown: 이전·다음
- Home/End: 처음·마지막
- F: 전체 화면
- [발표 대본](docs/발표대본.md): 검토본 기준 번호로 저장한 대본
