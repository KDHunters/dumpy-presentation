# GitHub 슬라이드 통합 검증

## 통합 후 공통 디자인 정리

사용자 요청에 따라 모든 30페이지의 배경을 `#1D1F1A`로 통일하고, `deck-chrome.css`를 세 문서에서 함께 사용한다. Footer는 좌측 `우리가락마구니사냥꾼 / Dumpy`, 우측 `1 / 30`–`30 / 30`으로 표시한다. 글꼴은 기존 Noto Sans KR 파일, 크기 18px, 두께 400, 줄높이 27px, 색상 `#FFFEF6`, 좌우 여백 100px, 하단 49px로 동일하다. 우상단의 HTML 브랜드 요소와 CSS로 생성하던 Dumpy 문구를 제거했다.

전체 30페이지를 실제로 이동하며 계산된 배경·Footer 스타일·쪽번호를 대조했다. 모든 값이 일치했고, 우상단 브랜드 요소나 Dumpy 가상 요소는 남아 있지 않았다. Footer와 우상단 브랜드 외의 슬라이드 내용은 보존했다. 아래의 원본 일치 기록은 이러한 공통 디자인 변경 이전 시점의 검증이다.

## Appendix 추가

`origin/main`을 다시 fetch해 동일한 최신 커밋 `ce70f5dc48064adabc58bbd45c12763ecb6e313d`를 확인했다. 원본의 `appendix` 문서 전체 5페이지를 로컬 26–30페이지에 추가했다. 본문 번호는 1–25, Appendix 번호는 원본대로 01–05로 유지한다.

- 포함: Appendix 표지, AI 워크플로, 성능 평가, 추천 시스템 개발 계획, 시스템 아키텍처
- `appendix-slides.html/css/js`로 HTML·공통 스타일·전용 스타일·렌더링 및 탐색 코드를 포함했다. 기존 CSS와 격리된 iframe에서 표시한다.
- 전용 Noto Sans KR TTF와 아키텍처 PNG를 함께 가져왔다. 기존 WOFF2 폰트 2개를 포함한 4개 자산은 원본과 바이너리가 일치한다.
- GitHub README의 발표자료 링크를 직접 클릭해 배포본을 열었다. Appendix 5페이지의 총 302개 요소 및 가상 요소에서 텍스트·글꼴·색상·배치·전환 설정이 모두 일치했다.
- 아키텍처의 양쪽 스크린샷, 표지·추천 시스템의 로컬 스크린샷을 확인했다. 1280×720과 390×844에서 고정 16:9 비율을 확인했다.
- 25↔26 경계, Appendix 이전·다음, 클릭 이동, Home/End, F 전체화면 진입·해제 및 기존 가져온 본문으로의 복귀를 확인했다. 터치 이동 코드는 원본의 60px 기준과 방향 판정을 그대로 연결했다.
- 기존 25개 슬라이드 HTML은 변경되지 않았다. Appendix의 5개 DOM 구조·속성·텍스트는 원본과 일치한다. 모든 JS·CSS 구문, 파일 참조, 중복 ID 검사를 통과했다.

아래는 본문 2–16페이지를 처음 통합했을 때의 기록이다.

- 기준 커밋: `ce70f5dc48064adabc58bbd45c12763ecb6e313d` (`origin/main`)
- 비교 배포본: https://kdhunters.github.io/dumpy-presentation/
- 로컬 구성: 기존 표지 + 배포본 2–16페이지 + 기존 2–10페이지 = 25페이지

## 포함 범위

배포본의 실제 탐색 순서에서 2–16페이지를 가져왔다. 원본 `new` 문서의 12개 슬라이드와 확장 상태 3개로 구성된 15페이지다. 페이지 4는 마인드 원더링 확장, 페이지 10은 인용문 확장, 페이지 15는 안내문 확장이다.

원본 HTML, 필요한 CSS·키프레임, 렌더링 상태 전환 코드를 로컬 파일로 포함했다. 기존 자료와 CSS가 충돌하지 않도록 하나의 공유 iframe에서 렌더링한다. 같은 슬라이드의 확장 상태 사이에 iframe을 다시 생성하지 않아 전환이 유지된다. 전체 페이지 탐색은 `deck.js`로 연결한다.

선택 범위에는 이미지·영상 의존성이 없다. Noto Sans KR 폰트 2개는 기존 `public/fonts` 파일과 원본의 SHA-256이 같아 재사용한다. 발표 중 GitHub 파일을 불러오지 않는다.

## 검증 결과

- 배포본과 로컬의 2–16페이지를 순서대로 키보드로 이동하며 비교했다.
- 15개 상태의 총 439개 요소에서 텍스트·클래스, 요소 및 `::before`·`::after`의 글꼴·크기·색상·배치·애니메이션·전환 설정이 일치했다. 전환 도중 크기가 바뀌는 7·10페이지는 전환 완료 후 다시 비교했다.
- 7·16페이지의 완료 화면을 양쪽 스크린샷으로 대조했다. 확장 상태 3개도 원본과 동일하게 활성화되었다.
- 1↔2, 16↔17 경계 이동, Home/End, 가져온 화면 클릭 이동, F 전체화면 진입·해제를 확인했다.
- 기존 AI 정리 시연에서 완료 상태와 체크 3개, 일정 시연에서 밤으로 이동 및 태스크 추가, 원문 시연의 강조 표시를 확인했다.
- 기존 10개 슬라이드의 HTML은 페이지 번호·접근성 페이지 번호 외에 통합 직전과 동일하다. 가져온 12개 슬라이드 HTML도 원본과 동일하다.
- 모든 JS 구문과 CSS 파싱, 로컬 파일 참조를 검사했다. 누락된 참조 파일과 중복 ID가 없다.

기존 요청대로 탐색 안내 UI는 표시하지 않는다. 배포본의 외부 탐색 버튼은 가져오지 않았으며, 슬라이드 내부 화면과 동작을 비교했다.

## 기존 코드 정리

삭제된 페이지의 CSS, 사용하지 않는 편집·저장 기능, 숨겨진 탐색 UI의 코드, 불필요한 변수·키프레임·중복 선언을 정리했다. 정리 전후 기존 420개 요소의 주요 계산 스타일을 비교해 차이가 없음을 확인한 후 통합했다. 원본 이미지 등 자료 파일은 보존했다.
